Выгрузить логи контейнера
docker logs pinger > pinger_logs.txt

Определите по логам общее количество запусков команды ping и какое общее количество отправленых запросов
количество запусков 

Get-Content pinger_logs.txt | Select-String "PING netology.ru" | Measure-Object

Общее количество запросов
 Get-Content pinger_logs.txt | Select-String -Pattern '\d+(?= bytes)' | ForEach-Object { $_.Matches.Count } | Measure-Object -Sum
